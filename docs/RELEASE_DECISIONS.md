# Decisions before commercial release

* Swiss Ephemeris licence: Astrodienst describes an AGPL path and a Professional Licence path. The owner must select a path before public distribution of a combined application or public operation and arrange any purchase separately. This prototype does not assign an open source licence to Vela on the owner's behalf.
* Knowledge rights: identify permitted editions and translations before ingesting text. Do not copy a modern copyrighted translation just because the underlying work is old.
* Hosting: this foundation is a local FastAPI service plus a Vite interface. No public service, sign in system or production database is configured.
* Traditional method selection and review: schools, sources, dasha conventions, aspects and remedies must be documented and reviewed. There are no traditional interpretations in milestone 1.
* Brand: Vela is a working name. Trade mark, domain and competitor checks remain outstanding.
